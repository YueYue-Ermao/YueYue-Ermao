### [Learn English Anytime · 随时学英语](https://github.com/YueYue-Ermao/learn-english-anytime)

一款面向职场人和学生的原生 macOS 英语学习工具：在网页、Office 和常见应用中选中英文即可查看释义与发音；需要把中文自然地表达成英文时，也可以获得结合场景的建议，并把有用的单词和句子收藏到本地学习中心。

A native macOS assistant that helps professionals and students understand selected English, hear pronunciation, find natural English expressions for real situations, and save useful words and sentences—without leaving their workflow.
